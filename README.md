\# Automated Image Resizer Service



Deep Learning powered image resizer using Flask + PyTorch + OpenCV.



\## Features

\- Smart AI Resize

\- Super Resolution (upscale 2x, 3x, 4x)

\- Exact size \& percentage scaling

\- PNG / JPG / WebP output

\- Before/After preview

\- Download resized image
